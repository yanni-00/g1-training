# Skill: $consolidate

**Purpose**: 将有效实验的结论与已知限制增量整理到 `.oma/memory.md`，使后续决策不重复旧误判。
**验证状态**: 流程 / 模板已整理，真实跨任务经验沉淀待验证。
**Gate in**: 无；train / tune 周期结束或用户要求时调用。
**Gate out**: 更新 memory.md，报告公共训练候选的处理结果；不改轮次真源、接受基线或运行权限。

## 读取与核对

1. 先读 memory 当前有效结论，再从 decision_log 定位尚未处理的已终判轮；trajectory 只是索引镜像，不能单凭时间戳或 completed 事件统计算法成功。
2. 读取相关 results / verdict 和任务卡的目标、协议、增益门与失败分支；更正旧结论时回查对应源文件，缺数据记未知。
3. 使用 [判定、产物与下一步](../train/review.md) 的证据类型、可比轮次和基线规则；不另设默认 std 倍数、种子数或无增益次数。

## 增量整理

格式以 `.oma/templates/memory.md` 为准，不在此重复整份模板；已有旧表保留数据，按需整理字段，不能因升级清空已有经验。

| 表 | 纳入条件 |
|---|---|
| Dead Ends | 有效实验支持的失败范围及必要混变量检查；广度不足的单点未达标留在本轮结论 / 待验假设，不升级为不可能 |
| Working Patterns | 可比较实验支持的效果，明确适用条件、实际训练广度与副作用；没有独立重复就保留局部证据限定，不称统计显著或通用默认值 |
| Open Hypotheses | 尚待鉴别的解释或下一步方向；来源、未知项及实际状态明确，预期收益无数据则写未知 |

同一方向只保留一个当前条目。新增证据补入原行；假设被检验、撤回或替代时更新其有效状态，并在原行保留旧结论、旧适用范围、修正来源和日期。历史实验与冻结判定不重写，不同时保留相互矛盾的“有效”条目；不再要求无限只追加，也不删除纠正链。

无增益追踪按任务卡标准逐轮核对可比较的有效算法实验，列实验 ID 与当前目标 / 协议分段；不计行政恢复、接入或评测故障、重复看护和中途趋势。缺标准 / 实验数据时计数未知，不机械加一。达到注册触发门则报告框架反思，先检验搜索空间假设，再决定是否继续。

## 团队公共训练经验

train / tune 约定的阶段沉淀应主动执行，不等待 human 再次发起。除项目 memory 外，检查是否有可复用的算法、观测、奖励、数据、控制、训练或评测结论。单轮也可保留明确场景限制的定性教训，不因缺独立种子一律忽略公共候选；没有证据的推测仍留在 memory，不强行生成 lesson。

先 `oma xp index --format md` 查重，相关才 show。团队正文使用配置的 `experience/lessons/{category}/`，索引复用同仓库 lessons_index.json，格式 / 新增 / 修订 / 作废遵循该库 LESSONS_LIFECYCLE.md；默认路径由 OMA configs/experience.json 提供，实例可用 config.experience.lessons_dir 明确覆盖。禁止另建 xp-index 或回退个人目录。

符合条件时提炼为团队原生 frontmatter 的正文，给实际实验 / 数据出处、适用范围、反例与置信度；复用已有结论则修订原条，不重复建文件。新增可用 `oma xp add --file <正文.md> --description <索引摘要>`，命令复用团队校验器；旧文修订 / 作废仍走团队生命周期，不使用个人 XP 的直接删除 / 标签重写。草稿用既有本轮 work，成功且确认无其他消费者后整理，不额外建长期候选账本。

OMA 的任务编排、权限、恢复、文件管理等机制经验留在基座 docs / 代码，不进入训练 lessons。公共经验入库只改本地团队仓库；Git 提交 / 推送按独立授权。已有明确范围与足够证据时不重复征求确认；范围有歧义、证据冲突或结论需 owner 决策时说明阻塞，不擅自扩大适用域。

报告分别写明：本地 memory 更新、公共训练 lesson 新增 / 修订路径及校验结果，或“无新增 / 证据不足 / 待处理”的具体原因。只有 memory 改动不称为公共入库完成；路径接入与流程规约不等于已自动提炼历史两个 loop 或已经完成跨任务实证验证。

## 完成检查

- 当前有效条目无重复、每条有真实实验 / 文件出处；反例、撤回和适用限制未丢失。
- 训练种子与评估初态没有混算；未知收益没有用示例值或经验估算填补。
- 无增益追踪与有效实验 ID、任务卡触发标准一致；原接受基线未被候选或局部门自动替换。

报告本地有效结论、公共训练候选处理结果、待验证事项与是否触发反思；所有数量来自实际核对，不输出旧 Budget Tracker。
